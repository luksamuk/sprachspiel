Ask-AI (ask-ollama-rs) Architecture

Rust CLI for Ollama LLMs — v0.40.0 | ~44K LoC | 90+ source files | 12 feature flags

Entry Points

  • • Positional query / pipe / stdin
  • • 7 subcommands (query, chat, translate, ocr, vision, summarize, completion)
  • • Chat REPL with 20+ slash commands
  • • --list (models), --init-config

Core Engine

  • • CustomCoordinator: tool loop, overflow detect, events
  • • Context overflow: 75%/88%/94%/97% thresholds
  • • Continuation: auto-compact + ephemeral resume (max 3)
  • • Model resolution: 5-level chain (CLI → config → default → builtin → user)

Storage & Retrieval

  • • SQLite: content_items, chunks, embeddings, conversations, facts, todos
  • • Hybrid RAG: BM25 (0.4) + Vector (0.6) via RRF
  • • FTS5 + sqlite-vec 768d / Matryoshka 256d
  • • Facts: heuristic classify, decay, conflict detect, <facts> injection

Extensibility

  • • 12 feature flags, 40+ built-in tools
  • • Skills: project > user > builtin, on-demand loading
  • • SOUL.md personality, AGENTS.md project context
  • • External CLI tools via tools.toml + Landlock sandbox

Specialized Modes

  • • Translate: 100+ languages, translategemma model
  • • OCR: glm-ocr:bf16, 4 modes (text/table/figure/formula)
  • • Vision: base64 images, any vision-capable model
  • • Summarize: dedicated pipeline, no tools

UI / Output

  • • termimad markdown: dark/light/mono skins
  • • indicatif + rattles spinners with suspend
  • • ChatView trait (future TUI via ratatui)
  • • Status bar: model, context %, tools, session
