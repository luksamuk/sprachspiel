# Architecture Decision Records

> **Documentos históricos e decisórios.**
>
> Estes documentos registram **por que** uma decisão foi tomada — a racionalidade, as
> alternativas consideradas, o que foi descartado e por quê. Eles **não** descrevem como o
> código se comporta hoje: para isso, veja [Arquitetura](../development/README.md) e o
> código-fonte.
>
> Trate-os como documentação de consulta. Uma decisão registrada aqui pode ter sido
> superada; se o código contradiz um ADR, **o código está certo** e o ADR precisa de uma
> nota de supersessão, não o contrário.
>
> Estes documentos foram extraídos de `IMPLEMENTATION.md` durante a consolidação do backlog
> (LUC-140). A intenção é isolá-los do restante da documentação, que descreve o estado atual.
