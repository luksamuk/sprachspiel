# v0.25.0 - Project-Aware Query Mode

**Priority:** HIGH  
**Status:** PLANNED  
**Date:** 2026-03-03

---

## Problem Statement

Query mode currently has no access to conversation history. When running `ask query "What did we discuss about Wittgenstein?"`, it responds without context from previous chats in that project.

This makes query less useful for quick questions that benefit from project history.

---

## Solution Overview

Enable query mode (and legacy mode) to retrieve context from the project's conversation history, using the same RAG system as chat mode, but without persisting new messages.

| Feature | Chat | Query (Current) | Query (Proposed) |
|---------|------|-----------------|------------------|
| AGENTS.md | ✅ | ✅ | ✅ |
| System context | ✅ | ✅ | ✅ |
| Tools | ✅ | ✅ | ✅ |
| Retrieval from DB | ✅ | ❌ | ✅ |
| Conversation history | ✅ | ❌ | ✅ (read-only) |
| Persists messages | ✅ | ❌ | ❌ |
| Database | ✅ | ❌ | ✅ (read-only) |

---

## Design Decisions

### 1. Scope of Retrieval

**Decision:** Search ALL sessions in the project.

**Reasoning:**
- Query is for quick questions about the project
- Full project history is more useful than single session
- Matches "new session with accumulated context" concept

### 2. Retrieval Limit

**Decision:** Same as chat (5 messages via RRF).

**Reasoning:**
- Proven to work well
- Reasonable token cost
- Sufficient context for most queries

### 3. Persistence

**Decision:** None - query remains ephemeral.

**Reasoning:**
- Query is one-shot, doesn't create conversation
- No session to persist
- Consistent with current behavior

### 4. AGENTS.md

**Decision:** Keep AGENTS.md in context.

**Reasoning:**
- AGENTS.md is project documentation, not conversation history
- Doesn't defeat the purpose of query
- Valuable context for all modes

### 5. Code Mode

**Decision:** No changes - continues without DB/history.

**Reasoning:**
- `--code` is for quick code questions
- Minimal context, fast response
- Keep current behavior

### 6. Graceful Degradation

**Decision:** If DB initialization fails, query continues without retrieval.

**Reasoning:**
- Query should work even without DB
- No hard failure for missing database
- Falls back to current behavior

## Implementation

### Phase 1: Extend search_hybrid() for project_id

**File:** `src/db/operations.rs`

Add `project_id` parameter:

```rust
pub fn search_hybrid(
    &self,
    query: &str,
    embedding: &[f32],
    conversation_id: Option<&str>,  // Specific conversation
    project_id: Option<&str>,        // Project-wide search
    limit: usize,
    keyword_weight: f32,
    semantic_weight: f32,
) -> Result<Vec<SearchResult>>
```

**Logic:**
- `conversation_id` specified → search that conversation
- `conversation_id = None`, `project_id` specified → search all project conversations
- Both `None` → search all conversations (global)

**SQL changes:**
```sql
-- keyword search
WHERE (conversation_id = ?1 OR ?1 IS NULL)
  AND (project_id = ?2 OR ?2 IS NULL)

-- semantic search
WHERE (conversation_id = ?1 OR ?1 IS NULL)
  AND (project_id = ?2 OR ?2 IS NULL)
```

### Phase 2: Create build_query_context()

**File:** `src/retrieval/context_builder.rs`

New function for query mode:

```rust
pub async fn build_query_context(
    project_id: Option<&str>,
    db: &Arc<Database>,
    embedding_client: &Arc<EmbeddingClient>,
    user_query: &str,
    config: &RetrievalConfig,
    use_debug: bool,
) -> ContextResult
```

This function:
1. Generates embedding for query
2. Calls `search_hybrid()` with `project_id`
3. Enriches results with conversation context
4. Formats as `<retrieved_context>`
5. Returns `ContextResult`

### Phase 3: Initialize DB/EmbeddingClient in query.rs

### Phase 4: Use build_query_context() in query.rs

**File:** `src/query.rs`

Replace message array construction:

```rust
let retrieval_config = RetrievalConfig::default();

let messages = if let (Some(db), Some(embedding)) = (&db, &embedding_client) {
    let context_result = build_query_context(
        project_id.as_deref(),
        db,
        embedding,
        &query,
        &retrieval_config,
        output_flags.debug,
    ).await;

    let mut messages = context_result.messages;
    messages.insert(0, ChatMessage::system(system_prompt.to_string()));
    messages.push(ChatMessage::user(query));
    messages
} else {
    vec![
        ChatMessage::system(system_prompt.to_string()),
        ChatMessage::user(query),
    ]
};
```

### Phase 5: Task-Local Context for Remember Tool

**File:** `src/query.rs`

Wrap coordinator.chat() with context:

let result = if let (Some(db), Some(embedding)) = (&db, &embedding_client) {
