## PHASE 1: Auto-Compaction

### Design Decisions

1. **When to compact:** After assistant response (before next user input)
2. **Trigger levels:**
   - Warning (≥72%): Silent auto-compact
   - Overflow (≥80%): Silent auto-compact (more urgent)
3. **Output:** Single line `[Auto-compacted context at 72%]` in gray
4. **No configuration:** Always enabled, undefined behavior without it

### Implementation

#### 1.1 ContextStatus Methods

**File:** `src/context_overflow.rs`

Add new methods:
- `is_warning()` - Returns true for Warning status
- `is_overflow()` - Returns true for Overflow status
- Modify `needs_compaction()` - Returns true for Warning OR Overflow

```rust
impl ContextStatus {
    pub fn needs_compaction(&self) -> bool {
        matches!(self, ContextStatus::Warning { .. } | ContextStatus::Overflow { .. })
    }
    
    pub fn is_warning(&self) -> bool {
        matches!(self, ContextStatus::Warning { .. })
    }
    
    pub fn is_overflow(&self) -> bool {
        matches!(self, ContextStatus::Overflow { .. })
    }
}
```

#### 1.2 Auto-Compact Function

**File:** `src/chat/repl.rs`

Create helper function:

```rust
async fn auto_compact_if_needed(
    ollama: &ollama_rs::Ollama,
    model_config: &ModelConfig,
    session: &mut ChatSession,
    settings: &Settings,
    agents_md: Option<&str>,
    storage: &ConversationStorage,
    status: &ContextStatus,
) -> bool {
    if !status.needs_compaction() {
        return false;
    }
    
    match compact_conversation(ollama, model_config, session, settings, agents_md).await {
        Ok((summary, range)) => {
            session.set_compacted_summary_with_range(summary, range);
            
            if !session.anonymous {
                let _ = session.save(storage);
            }
            
            eprintln!("\x1B[90m[Auto-compacted context at {}%]\x1B[0m", status.usage_percent());
            true
        }
        Err(e) => {
            eprintln!("\x1B[31mAuto-compaction failed: {}\x1B[0m", e);
            false
        }
    }
}
```

#### 1.3 Integration Point

Call after assistant response is saved:

## PHASE 2: Visual Metrics in /context

### Design Decisions

1. **Bar chart:** 20 characters wide, filled with `█`, empty with `░`
2. **Colors:** Green < 72%, Yellow 72-80%, Red ≥ 80%
3. **Percentage shown:** As number after bar
4. **Token counts:** Shown below bar

### Example Output

```
Context Information:
  Model:          llama3.1 (32K context)

  Context Utilization:
    ██████████░░░░░░░░░ 50%
    16,384 / 32,768 tokens

  Status: OK

  Token Breakdown:
    System prompt:     ~5,854 tokens
    Tool definitions:     ~120 tokens (6 tools)
    Conversation:      ~10,410 tokens (15 messages)
    ────────────────────────────────────────────
    Total used:        ~16,384 tokens
    Available:         ~16,384 tokens
```

### Color Rules

| Usage | Color | Status Text |
|-------|-------|-------------|
| < 72% | Green (`\x1B[32m`) | OK |
| 72-80% | Yellow (`\x1B[33m`) | WARNING (approaching limit) |
| ≥ 80% | Red (`\x1B[31m`) | OVERFLOW (auto-compact triggered) |
